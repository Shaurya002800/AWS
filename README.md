# RewindGuard X

RewindGuard X is a three-person AWS course project about preventing erased data from reappearing after a database restore, stale queue replay, S3 version recovery, or search-index rebuild. The repository currently contains the technical blueprint and team execution plan; implementation has not started.

Start with the [technical blueprint](docs/RewindGuard_X_Complete_Technical_Blueprint.docx), [team execution plan](docs/TEAM_EXECUTION_PLAN.md), [project configuration](docs/PROJECT_CONFIG.md), and [current status](docs/STATUS.md). Contributor agents should also read [AGENTS.md](AGENTS.md).

The integration branch is `main` at `https://github.com/Shaurya002800/AWS.git`. Development happens on reviewed feature branches. Only Member 1 connects to the AWS account. The project has a zero out-of-pocket spending rule; all local work must run without AWS credentials. The local setup and test commands in the plan are targets to implement and are not yet runnable.
